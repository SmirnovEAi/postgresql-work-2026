# Рабочий репозиторий для курсовой работы по администрированию PostgreSQL

Данный репозиторий не требуется форкать и открывать пулл-реквест. Клонируйте его и используйте для непосредственного выполнения практики в рамках курсовой работы.

При выполнении практических заданий необходимо фиксировать все действия и оформлять отчет (см. репозиторий `db-course/postgresql-report-группа`).
