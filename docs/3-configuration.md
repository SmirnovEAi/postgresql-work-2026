# 3) Конфигурирование сервера

1. Получите с помощью `psql` список параметров, для изменения которых требуется перезапуск сервера
2. В файле `config/postgresql.conf` допустите синтаксическую ошибку при изменении `max_connections`
3. Перезапустите сервер, проверьте состояние сервиса, после чего проверьте его логи
4. Исправьте ошибку и перезапустите сервис
