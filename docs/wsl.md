# Установка WSL2

### Подходит для:
- Windows 10 (версия 2004 и новее, сборка 19041+)
- Windows 11

---

## Шаг 0. (необязательный, только для Windows 10) Установка Windows Terminal
1. Откройте **Microsoft Store**.
2. В поиске введите **Windows Terminal** и установите приложение терминала. *(В Windows 11 этот шаг не нужен — приложение терминала поставляется в составе ОС).*

---

## Шаг 1. Установка WSL

### Вариант 1. Установка из командной строки — рекомендуется

1. Откройте Windows Terminal (оболочку "Командная строка" или "PowerShell") от имени администратора.
2. Выполните команду:

```cmd
wsl --install
```

Команда автоматически:

* включит необходимые компоненты Windows;
* установит WSL;
* установит необходимое для WSL2 ядро Linux;
* настроит WSL2 как версию по умолчанию;
* установит дистрибутив Ubuntu.

3. Перезагрузите компьютер.

---

### Вариант 2. Установка через графический интерфейс

Используйте этот вариант, если установка командой wsl --install недоступна или завершается ошибкой.

#### Шаг 1.1. Включение необходимых компонентов Windows

1. Откройте Пуск → Панель управления → Программы → Включение или отключение компонентов Windows
2. В открывшемся списке отметьте:  
   - **Платформа виртуальной машины (Virtual Machine Platform)**,
   - **Подсистема Windows для Linux (Windows Subsystem for Linux)**.

3. Нажмите **OK** → дождитесь установки компонентов.
4. Перезагрузите компьютер.  

#### Шаг 1.2. Установка обновления ядра WSL2 (только для Windows 10)

1. Откройте браузер и перейдите на страницу [Linux kernel update package for WSL2](https://aka.ms/wsl2kernel).
2. Скачайте `пакет обновления ядра Linux WSL2 для компьютеров x64` и установите его через мастер. *(В Windows 11 этот шаг не нужен — ядро уже встроено).*  

#### Шаг 1.3. Настройка WSL2 как версии по умолчанию

Откройте Windows Terminal и выполните:

```cmd
wsl --set-default-version 2
```

#### Шаг 1.4. Установка дистрибутива Linux в Microsoft Store
1. Запустите Microsoft Store.
2. В поиске найдите и установите дистрибутив **Ubuntu 26.04** (рекомендуется).

---

## Шаг 2. Первый запуск Ubuntu

1. Запустите Ubuntu:

* через меню **Пуск**;
* через новую вкладку Windows Terminal;
* либо командой:

```cmd
wsl
```

2. При первом запуске выполняется первоначальная настройка Linux. После неё необходимо создать пользователя Linux и задать пароль. При вводе пароля символы в терминале **не отображаются** — это нормальное поведение Linux. Введите пароль и нажмите Enter, затем повторите его для подтверждения. Учётная запись Linux является отдельной от учётной записи Windows.
