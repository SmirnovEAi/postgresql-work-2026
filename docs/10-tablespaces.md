# 10) Табличные пространства

1. Определите точку монтирования тома, содержащего каталог с данными сервера PostgreSQL
    - с помощью команды `docker volume ls` получите список томов
    - проверьте наличие в этом списке тома с именем, отраженном в конфигурационном файле `docker-compose.yml`
    - инспектируйте том с помощью команды `docker volume inspect имя_тома`
    - проверьте содержимое каталога, указанного в выводе предыдущей команды в пункте `Mountpoint`
2. Создайте новое табличное пространство и базу данных в нем
    - создайте пустой каталог в каталоге, являющемся точкой монтирования
    - в psql создайте новое табличное пространство с расположением в этом каталоге
    - убедитесь, что табличное пространство появилось в системном каталоге
    - создайте базу данных в новом табличном пространстве
    - проверьте содержимое каталога табличного пространства
3. Установите новое табличное пространство в качестве табличного пространства по умолчанию
    - измените для базы данных `template1` табличное пространство по умолчанию на новое табличное пространство
    - создайте новую базу данных без явного указания табличного пространства
    - проверьте табличное пространство по умолчанию у новой базы данных
4. Удалите новое табличное пространство
